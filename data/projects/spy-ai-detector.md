# Spy -- AI-Generated Text Detection System

## Overview

Spy is a machine learning system designed to determine whether a given text was written by a human or generated by artificial intelligence. The project began under the constraint that only classical machine learning algorithms could be used initially, and that the training dataset had to be built from scratch by the team. A total of 24,300 text samples were collected and curated across multiple datasets.

## Data and Problem Design

- Multiple datasets were assembled by collecting human-written and AI-generated texts from various sources
- The datasets were structured to reflect real-world scenarios, covering different text types and varying lengths
- Models were evaluated not only on training data but also on previously unseen texts to measure generalization performance

## Technical Approach

Three distinct modeling strategies were implemented and compared:

- **TF-IDF + Naive Bayes:** Baseline approach using term frequency-inverse document frequency features with a probabilistic classifier
- **TF-IDF + Logistic Regression:** Linear classification model applied to the same feature space, optimized through Grid Search hyperparameter tuning
- **BERT:** A transformer-based deep learning model added with advisor approval to benchmark against classical approaches

Each model outputs a percentage-based probability indicating how likely the input text is to be AI-generated.

## Architecture

- **Backend:** Flask API serving the trained models and handling prediction requests
- **Frontend:** React-based web interface allowing users to submit text and view detection results
- **Pipeline:** Text preprocessing, feature extraction (TF-IDF for classical models), model inference, and result presentation

## Technical Contributions

- Designed the data collection strategy and dataset structure
- Implemented TF-IDF feature extraction and trained Naive Bayes and Logistic Regression models
- Conducted Grid Search optimization to identify the best hyperparameter configurations
- Compared results across all three approaches to determine the highest generalization performance
- Trained the BERT model and benchmarked it against classical methods

## Results

- Achieved approximately 94% accuracy in detecting AI-generated text across different text types
- Demonstrated the practical impact of data quality on model performance
- Validated the importance of proper feature extraction and model selection in text classification tasks
